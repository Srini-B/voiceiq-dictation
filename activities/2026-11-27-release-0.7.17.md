# 2026-11-27: Release 0.7.17 (92)

## Why now

The owner asked for a release on 2026-11-27 07:15 UTC once everything planned had merged. That overrides the two-day gap for this release only. From here, the integrator decides release timing: a release goes out when the Hex and FluidVoice watch brings in something worth shipping, or when our own fixes add up to a clear improvement, at least two days apart unless something is broken.

## What ships

Everything merged since 0.7.16 (91):

- **Dictation:** #97 (send-on-pause; requests stream, so a cancelled early request is not billed), #105 (no backup request: one request per dictation), #92 (a dictation's text waits for its field on iPhone), #101 (shorter prompt), #112 (Tamil whole hours: "7 மணி", not "7:00 மணி").
- **Learning from edits:** #99 (neighbouring fixes learned as one phrase; rewording ignored), #109 (names fixed by ear learned; deleting a just-learned word forgets it).
- **iPhone keyboard:** #98 and #108 (row buttons, whole long words, Dictate mark with voice bars, highlight only when space applies it).
- **Meetings:** #100 (notes in one schema-bound call; usage metered).
- **Eval and docs:** #95, #96, #102, #104, #106, #110, #111.

The Mac app already removes the retired Chrome extension's native-host files at every launch (since 0.7.16); the notice still asks users to remove the extension from Chrome by hand.
