# 2026-11-12: Opt-in debug log on the Mac and iOS

## Why

The owner asked for a switch, on both apps, that writes down everything the
app does so a log can be sent with a bug report, and asked how long the iOS
logs already kept are retained. The answer is in `docs/DEBUG_LOG.md`: the iOS
session log keeps its newest 400 lines and the keyboard log its newest 100,
with no age limit; `transport.jsonl` keeps up to 2 MB plus one previous 2 MB
file; the unified log is rotated by the OS. None of them could be exported as
one file, and the unified log drops `info` lines at once.

## What changed

- `DebugLog` (VoiceIQBridge, so the keyboard and the Chrome host can use it):
  the switch, one file per process per day under `Logs/VoiceiQ`, 7 days and
  30 MB kept, redaction, export and clear.
- `Log.<category>` is now a `LogChannel` instead of an `os.Logger`. Call sites
  are unchanged. Each message still goes to the unified log, and to the debug
  log while it is on, so every existing log line is covered without editing
  the 250 call sites, and new code is covered by default.
- Settings changes, Keychain key saves, the keyboard's log and the Chrome
  extension host's start, sites, errors and stop are logged.
- Settings › Advanced on both apps: **Write a debug log**. The Mac exports,
  shows the folder, and clears; iOS shows the newest 500 lines, shares the
  whole log, and clears.

## Trade-off

`LogChannel` renders each message before handing it to `os.Logger` as one
public string, with `.private` and non-numeric `.auto` values replaced by
`<private>`. Production behavior is the same as before. With a debugger
attached, Xcode's console now shows `<private>` for those values too instead
of the values.

## Verification

On Linux, with Swift 6.2 and a stub `os` module, a scratch harness compiled
the real `DebugLog.swift` and `Log.swift` and checked the call-site shapes
the repo uses (`privacy:`, `format: .fixed(precision:)`, errors, Bools,
CGFloat, nested literals), the unified-log privacy, redaction of Gemini,
OpenAI, ElevenLabs, bearer, JWT, query-string and registered keys (and that
`keys=`, `tokens=` and request IDs survive), per-process day files, export
order, the 7-day and 30 MB pruning, clear, and off. All 24 checks passed. A
scan of all 251 `Log` call sites found only string literals with `privacy:`
and `format: .fixed(precision:)`. The Apple targets were not built here; the
combined build compiles them.
