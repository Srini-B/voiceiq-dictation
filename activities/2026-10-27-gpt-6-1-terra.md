# GPT-6.1 Terra replaces GPT-6 Astra as the OpenAI text model

2026-10-27.

## Why

OpenAI released `gpt-6.1-terra` on 2026-10-26 at $1 in, $0.05 cached and
$5 out per million tokens. Astra costs ten times that. Astra was chosen on
2026-10-21 only because it fixed misheard phrases that read as English
(`2026-10-21-mishearings-that-read-as-english.md`). The owner asked whether
Terra can do the same job.

## What changed

- `OpenAIConfig.writingModel` is `gpt-6.1-terra`. It drives every OpenAI
  text role: cleanup, Ask Anything, Translate, meeting notes and agent mode.
  A user's Formatting model override still wins.
- `PriceBook` has Terra at $1 in, $0.05 cached, $5 out per million tokens
  (developers.openai.com/api/docs/models/gpt-6.1-terra). The Astra row stays
  so that older History rows keep their cost.
- `openAIReasoningEffort` is unchanged. Terra takes `none`, so it gets
  `none`. Astra, still reachable through the override, keeps `low`.
- Agent mode already uses the Responses API, which Terra needs for tool
  calls, like Astra.

## Verification

Harness `.amp/in/terra/` (not committed). It is the `sensefix` and
`wordorder` harness: the app's current cleanup prompt built from
`PromptV1` and `DefaultWritingRules`, the MacBook dictionary, the app as
PLACE, called through CLIProxyAPI. Fixtures: 11 real mishearings, 14 jumbled
word orders, 22 controls, 3 runs each.

| | Astra, `low` (before) | Terra, `none` | Terra, `low` |
|---|---|---|---|
| Mishearings fixed | 22/33 | 21/33 | 18/33 |
| Word order fixed | 41/42 | 40/42 | 40/42 |
| Controls kept | 63/66 | 63/66 | 63/66 |
| List continuation (`fieldeval`) | 7/9, controls 15/15 | 6/9, controls 15/15 | not run |
| Latency p50 / p90 | 3.3 s / 7.6 s | 2.2 s / 3.4 s | 2.3 s / 3.4 s |

- The differences in fixes are one run or less per set, which is noise at
  3 runs. Both models miss the same hard cases (iPadOS, "but setup").
  Every control failure is "but status" turned into `git status`, which every
  model has failed since 2026-10-21.
- `ValidationGate` accepted all 423 outputs.
- A first run at 8 parallel calls hit HTTP 429 on 8 calls per model and made
  Terra's controls look worse (55/66). The table is the rerun at 4 parallel
  calls, with no errors.
- Cost of a median cleanup (8,576 prompt tokens, 21 out), uncached: Terra
  about $0.009, Astra about $0.087.
- Probes on Terra: the screenshot layout (developer message, image, then
  RAW) cleaned correctly in 3.1 s, and a Responses call with a function tool
  returned the tool call.
- `scripts/test.sh`: 143 tests pass.

Not verified: latency on OpenAI's own API (there is no OpenAI key on the Mac
mini; all calls went through CLIProxyAPI), and replays of Ask Anything,
Translate, meeting notes or agent mode runs. Not driven through a live
dictation in the installed app.

## Rollback

Set `OpenAIConfig.writingModel` back to `gpt-6-astra`, or set the
Formatting model override to `gpt-6-astra` on one device.
