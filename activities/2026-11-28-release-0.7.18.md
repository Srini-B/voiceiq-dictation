# 2026-11-28: Release 0.7.18 (93) from a branch

## Why a branch

Main switched from Gemini to AssemblyAI in #121 and is on release hold until that switch is verified (meetings measured, signed smoke test, and a decision on the LLM Gateway balance). The work merged between 0.7.17 and #121 doesn't depend on it, so 0.7.18 ships from `release-0.7.18-gemini`: main just before #121 (d60ace07) plus #120 cherry-picked. Main's AssemblyAI build will be 0.7.19.

## What ships

- **Meetings:** #114 (save each meeting as Markdown, off by default; `get_meeting` takes an optional time range), #116 and #120 (meetings UI: turns, notes header, list by day, an obvious recording state, overlapping calendar events matched by call service), #118 (meetings always on Gemini; a meeting that can't reach Gemini waits and resumes).
- **Eval and docs:** #115, #117, #119.
- The committed Info.plists gain the calendar usage text project.yml already had; release builds regenerate them, so shipped apps are unchanged by that.
