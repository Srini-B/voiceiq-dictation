# SCOWL 2026.02.25 evaluated for the keyboard, not adopted (2026-11-05)

**Why.** The keyboard's word list takes the capital spelling of names and
brands ("iPhone", "Monday") and its set of contractions from SCOWL's en_US
Hunspell dictionary, release 2020.12.07, through wooorm/dictionaries at
`8cfea40`. SCOWL published release 2026.02.25 (new words such as ChatGPT,
LLM, Kyiv and codebase, cleaner possessives). wooorm has not rebuilt `en`
since 2021, so the candidate was SCOWL's own release asset. The owner asked
to adopt it only if it helps and nothing gets worse.

**Candidate.** `hunspell-en_US-2026.02.25.zip` (187,271 bytes, sha256
`ac8e7331…f931179f9`), `en_US.dic` inside. wooorm's `en` is the same
dictionary: its license file is SCOWL's en_US Hunspell README, "normal"
dictionary, SCOWL size 60, one spelling variant per word. The 2026 README
records the command `mk-list --accents=strip en_US 60`; both files are
ASCII. Entries 49,568 → 47,551 (1,421 stems added, 3,438 removed; most
removals are words now produced by affix flags, such as `atone/LGDS` for
"atonement"), apostrophe entries 412 → 377. The generator was changed to
fetch the zip, check the sha256 and read `en_US.dic`, and `lexicon.bin` was
rebuilt from it. The emoji files stayed byte-identical. All of this was
reverted after the evaluation.

**Lexicon diff** (both builds decoded record by record):
- Words 82,846 → 82,846, pairs 242,342 → 242,342. Frequencies, flags and
  pairs are unchanged. The 65 apostrophe words are unchanged ("don't",
  "it's", "y'all", "I'm", "needn't" …). The new possessives have no effect,
  because SymSpell, which decides which words exist, has no possessives.
- Display spelling changes in 32 words, and nothing else changes.
  - Better: anthropic → Anthropic, french → French, ashkenazi → Ashkenazi,
    hasidic → Hasidic, midwesterner → Midwesterner, MasterCard →
    Mastercard, tangiers → Tangiers, roma → Roma, Redshift → redshift,
    Gen → gen.
  - Worse, common words capitalized: west → West (SymSpell count 173 M),
    billings → Billings (2.5 M), holiness → Holiness (1.5 M), atonement →
    Atonement (0.66 M), highness → Highness (0.46 M), magus → Magus,
    eth → ETH, tui → TUI. On space, the engine changes "west" to "West".
  - Worse, names lose their capital: Tues, Kiev, Estes, Josephs, Norsemen,
    Visigoths, Torahs, Salvadorean, Salvadorian, Danae, Reginae.
  - Neutral: Eur → EUR, aud → AUD, EST → est.
- Causes. The 2026 dictionary has no lowercase "west" at size 60. It has
  only `West/M`. The large (size 70) dictionary has `west/RZGJ`. This is an
  upstream data change. A search of en-wl/wordlist issues for "west" found
  no report of it. The other common-word
  regressions break the rule in docs/IOS.md. The 2026 file stores
  "holiness" as `holy/P`, "atonement" as `atone/L` and "billings" as
  `bill/J`. The generator's suffix list (-s, -es, -ies, -ed, -ing, -er,
  -ers, -ly) does not reach these forms, so it decides that Hunspell has
  no lowercase form. "jobs" and "as" stay lowercase, and "monday" still
  becomes "Monday".
- New terms do not reach the keyboard. ChatGPT, LLM, Kyiv, codebase,
  TikTok and influencer are not in SymSpell. 787 of the 1,421 added stems
  are not in SymSpell. Overall, 7,264 of the 47,551 stems in the 2026
  dictionary are missing from SymSpell. SCOWL has no counts, so it can add
  a word only at an invented count. The FUTO context model's vocabulary
  lacks these words too.

**Decision.** Not adopted. The decision rule requires no regression in
common words, and "west" becomes "West", along with holiness, highness,
atonement and billings. The new terms that motivated the upgrade do not
reach the lexicon. Apart from those, ten spellings get better and eleven
names lose their capital, and the hit rates are unchanged.

**Found on the way, not changed.** The current rule already capitalizes
lowercase words that Hunspell 2020 forms with a prefix or suffix flag:
"independence" (`dependence/IM`) becomes "Independence" on space in the
shipped engine, as do republican, reunion, reconstruction, honorable,
reformation, zen and goth. A rule that expands the affix file would fix
these (`.amp/in/scowl/variant_b.py`, 16 words with the 2020 file). The same
rule would also make 2026 viable for holiness, atonement and billings.
"west" stays lowercase under it only because `w/T` expands to "west", so
2026 would still need a decision on "west". Brand words such as ChatGPT
belong in a counted list like `CHAT_WORDS`, not in SCOWL.

**Rerun.** `.amp/in/scowl/` (git-excluded) holds the decoder (`dump.py`),
the entry statistics (`stats.py`) and the prototype. `.amp/in/ctxlm-eval/swipe/`
holds the harness (`build-swift.sh predict`, `eval_shipped.py` with `LEX`,
`OUTDIR` and `CHANGED`, and `misspellings.py` with `LEX`).

**Rollback.** Nothing shipped. Delete this file.
